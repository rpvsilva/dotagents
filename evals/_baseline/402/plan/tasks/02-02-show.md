## What to build
`todo show ID` prints the item's fields and all its notes in order, each with its time in local time. Unknown ID exits 2.

## Acceptance criteria
- [ ] New `todo/cli/commands/show.py`, found by command discovery.
- [ ] Output, one line each, `-` when empty: `id: 1`, `title: ...`, `done: yes|no`, `due: YYYY-MM-DD`, `priority: ...`, `tags: #a #b`, `every: ...`, `parent: N`, `snoozed until: YYYY-MM-DD`, `blocked on: 3,5`, `updated: YYYY-MM-DD HH:MM` (local); then `notes:` and one line per note `  YYYY-MM-DD HH:MM  text` (local), or `notes: none`.
- [ ] Hidden sync fields (`series_id`, `occurrence`, `anchor_day`) are not printed.
- [ ] Stored text printed comes through `normalize_title`/`normalize_note` already; nothing else from the file reaches the terminal raw.
- [ ] Unknown ID exits 2 with `todo: error: no item ID`.
- [ ] Tests build the expected local times with `datetime.astimezone()`, never by setting `TZ`.

## Check
`tests/cli/test_show.py` (new; notes written with `Store.update` or a JSON row, not through `todo note`), then the full Checks command.
