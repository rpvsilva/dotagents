## Acceptance criteria

- [ ] The `todo done` paragraph lists what the next occurrence keeps (title, tags, priority, rule, parent, blocks) and that notes and a snooze stay with the done one.
- [ ] `## Known limits`: older versions stop with an error on a todo file holding a parent, notes, a snooze or blocks.

## Interactions
- `--due`, `--tag`, `--priority`, `--every` on `todo add`: `--parent` combines with each, in any order after TITLE.
- Recurring series (`todo done`, `todo skip`, `todo stop`): the next occurrence and a skipped item keep `parent`.
- Filters `--open`/`--done`/`--tag`/`--priority`/`--search`/`--sort`/`--overdue` and `todo search`: a child whose parent is filtered out lists at top level; counts cover every child.
- `todo export`: no tree, no count; output unchanged.
- `todo remind`: no indent, no count.
- `todo sync`: `parent` travels in the whole item; a parent id that a sync collision reused is a known limit.
- Exit codes: unknown `--parent` exits 2; existing commands keep exit 1 for an unknown id.
