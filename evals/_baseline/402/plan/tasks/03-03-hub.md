## What to build
README `Usage` documents `todo snooze ID --until DATE` and `--snoozed` on `todo list` and `todo export`, and that snoozed items hide from `list`, `search`, `export`, `remind` and `next` until DATE. Check the wiring: `search` takes `--snoozed`'s default; `done` and `skip` clear a snooze; `sync` carries it.

## Interactions
- Command discovery (ticket 01) and `tests/cli/test_registry.py`: a hub file (map.md `Lanes`) no feature task edits; after the sync, this task sets its `names` list to every command on the branch.
- Filters (`--open`/`--done`/`--tag`/`--priority`/`--search`/`--sort`/`--overdue`): `--snoozed` combines with each.
- `todo search`: hides snoozed items by `todo list`'s defaults.
- `todo export`: hides them too; `--snoozed` exports only them; columns unchanged.
- `todo remind`: hides them.
- Recurring series (`todo done`, `todo skip`): both clear the snooze; the next occurrence starts unsnoozed.
- Subtasks (ticket 01): a hidden snoozed parent lets its children list at top level; `done/total` still counts snoozed children.
- `todo sync`: `snoozed_until` travels in the whole item.
- `--due` date rules: `--until` uses the same strict `YYYY-MM-DD` parser.
