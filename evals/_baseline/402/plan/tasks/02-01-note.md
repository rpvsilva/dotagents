## What to build
`todo note ID TEXT` adds a note to item ID, stamped with the time it was added (UTC, `Store.clock`); notes keep the order they were added in. Prints `noted ID`. Unknown ID exits 2 with `todo: error: no item ID`; empty text, text over 1000 characters, or a 101st note exits 2; nothing is saved then.

## Acceptance criteria
- [ ] New `todo/storage/notes.py`: `add_note(store, item_id, text)` uses `normalize_note` and `MAX_NOTES` from `todo/storage/model.py`, appends `Note(at=store.clock(), text=...)` through `Store.update`, so `updated_at` moves too.
- [ ] New `todo/cli/commands/note.py` (`register`/`run`), found by command discovery with no other edit.
- [ ] Two notes keep their order and distinct stamps (patch `Store.clock` with `monkeypatch`).
- [ ] Non-printable characters are stored as `?`.
- [ ] Unknown ID, empty text, 1001 characters, the 101st note: exit 2, todo file unchanged.
- [ ] A bad todo file still exits 1 (`StoreError` re-raised before `ValueError`).
